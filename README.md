# Thess Metro Position

Ένα μοντέρνο, στατικό dashboard που δείχνει την **εκτιμώμενη ζωντανή θέση** των συρμών του Μετρό
Θεσσαλονίκης πάνω σε πραγματικό γεωγραφικό χάρτη (πραγματικοί δρόμοι, πραγματικές συντεταγμένες
σταθμών), όχι σχηματικό διάγραμμα.

## Γιατί "εκτιμώμενη"

Δεν υπάρχει επίσημο δημόσιο API για ζωντανή θέση συρμών. Αντ' αυτού, η εφαρμογή προσομοιώνει το
ωρολόγιο πρόγραμμα:

- Πρώτο δρομολόγιο κάθε μέρα στις **05:15**, από τον δυτικό τερματικό σταθμό.
- Ώρα κλεισίματος δικτύου: Δευ–Πέμ 23:00, Παρ–Σάβ 02:00 (επόμενη μέρα), Κυρ 00:30 (Δευτέρα).
- Συχνότητα δρομολογίων στον κοινό κορμό: **ανά 3′** σε ώρες αιχμής, **ανά 5′** τις υπόλοιπες ώρες·
  μόλις ανοίξει η επέκταση Καλαμαριάς, η αιχμή σφίγγει σε **ανά 1,5′** (επιβεβαιωμένο από τον
  operator). Οι ώρες αιχμής (07:00–09:30, 14:00–16:30, 19:00–21:00, Δευ–Παρ) είναι παραδοχή του
  μοντέλου και μπορούν να αλλάξουν εύκολα στο `js/data.js`.
- Χρόνος διαδρομής: ~16′ στον κορμό (Ν. Σιδηροδρομικός Σταθμός → 25ης Μαρτίου) + ~3′ στον κλάδο
  προς Νέα Ελβετία ή ~11′ στον κλάδο της επέκτασης προς Μίκρα.

**Τοπολογία σε σχήμα Y:** η γραμμή είναι ενιαία μέχρι τον σταθμό **25ης Μαρτίου**, όπου διακλαδίζεται:
ο ένας κλάδος οδηγεί στη Νέα Ελβετία (ήδη σε λειτουργία), ο άλλος στην επέκταση Καλαμαριάς
(Νομαρχία–Καλαμαριά–Αρετσού–Νέα Κρήνη–Μίκρα, 27/08/2026). Η επέκταση **δεν** συνεχίζει μετά τη
Νέα Ελβετία — ξεκινά νωρίτερα, από τη διακλάδωση. Μόλις ανοίξει, τα δρομολόγια χωρίζονται σε
αναλογία **2:1 υπέρ της Καλαμαριάς** (από κάθε 3 συρμούς που φεύγουν από τον κορμό, οι 2 πάνε προς
Μίκρα και 1 προς Νέα Ελβετία) — επιβεβαιωμένη αναλογία, όχι υπόθεση 50/50.

Με βάση αυτά τα δεδομένα, υπολογίζεται πόσοι συρμοί κυκλοφορούν αυτή τη στιγμή προς κάθε
κατεύθυνση/κλάδο και πού βρίσκονται πάνω στη γραμμή. **Δεν πρόκειται για πραγματικά δεδομένα GPS.**

Στοιχεία δρομολογίων/σταθμών επιβεβαιώθηκαν βάσει [thessmetro.gr](https://www.thessmetro.gr) και
δημοσιευμάτων για την επέκταση προς Καλαμαριά. Οι συντεταγμένες κάθε σταθμού προέρχονται από το
infobox του αντίστοιχου άρθρου στην Αγγλική Wikipedia (πραγματικές, όχι σχηματικές θέσεις).

## Χαρακτηριστικά

- Πραγματικός γεωγραφικός χάρτης ([Leaflet](https://leafletjs.com/) πάνω σε πλακίδια CARTO Dark
  Matter/OpenStreetMap) με τη γραμμή σε σχήμα Y (11 σταθμοί κορμού + 2 σταθμοί προς Νέα Ελβετία +
  5 σταθμοί επέκτασης Καλαμαριάς) στις πραγματικές τους θέσεις, με ζωντανά κινούμενους δείκτες
  συρμών ανά κλάδο/κατεύθυνση.
- Ρολόι σε ώρα Ελλάδας (Europe/Athens) ανεξάρτητα από τη ζώνη ώρας του επισκέπτη.
- Ένδειξη ανοιχτού/κλειστού δικτύου και τρέχουσας συχνότητας (αιχμή/κανονικό).
- Ένδειξη πόσοι συρμοί είναι αυτή τη στιγμή σε κίνηση, πάνω στο γνωστό μέγεθος του στόλου (18
  συρμοί σήμερα, 33 μετά την επέκταση — δεδομένα του operator). Ο στόλος λειτουργεί σαν πάνω όριο
  στην προσομοίωση, όχι απλή ένδειξη.
- Αυτόματη ενεργοποίηση της επέκτασης Καλαμαριάς στις 27/08/2026, με αντίστροφη μέτρηση μέχρι
  τότε· τότε ενεργοποιούνται μαζί η αιχμή του 1,5′ και ο διαχωρισμός δρομολογίων 2:1 υπέρ Καλαμαριάς.
- Κλικ σε σταθμό → επόμενες 3 αφίξεις ανά κατεύθυνση, ομαδοποιημένες ανά τελικό προορισμό στους
  κοινούς σταθμούς του κορμού.
- Σκούρο, responsive design· τα ονόματα σταθμών εμφανίζονται μόνιμα μόλις μεγεθύνεις αρκετά (οι
  πραγματικοί σταθμοί απέχουν μόνο μερικές εκατοντάδες μέτρα μεταξύ τους), αλλιώς φαίνονται με
  hover/tap.

## Εκτέλεση τοπικά

Δεν χρειάζεται build step — καθαρό HTML/CSS/JS. Απλά σέρβιρε τον φάκελο στατικά, π.χ.:

```bash
python3 -m http.server 8000
# άνοιξε http://localhost:8000
```

## Deploy

Μπορεί να φιλοξενηθεί σε οποιοδήποτε static hosting (π.χ. GitHub Pages): ενεργοποίησε το Pages
για αυτό το repo/branch, με root τον φάκελο του repository.

## Δομή

```
index.html          Markup της σελίδας
css/style.css        Στυλ (dark theme, χάρτης, panels)
js/data.js           Σταθμοί (πραγματικές συντεταγμένες), μοντέλο ωραρίου
js/app.js            Μηχανή υπολογισμού δρομολογίων + Leaflet rendering + interactivity
vendor/leaflet/      Αυτοφιλοξενούμενη βιβλιοθήκη Leaflet (χωρίς εξάρτηση από CDN)
```
