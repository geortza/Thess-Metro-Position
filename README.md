# Thess Metro Position

Ένα μοντέρνο, στατικό dashboard που δείχνει την **εκτιμώμενη ζωντανή θέση** των συρμών του Μετρό
Θεσσαλονίκης πάνω σε πραγματικό γεωγραφικό χάρτη (πραγματικοί δρόμοι, πραγματικές συντεταγμένες
σταθμών), όχι σχηματικό διάγραμμα.

## Γιατί "εκτίμηση"

Δεν υπάρχει επίσημο δημόσιο API για ζωντανή θέση συρμών. Αντ' αυτού, η εφαρμογή προσομοιώνει το
**επίσημο ωρολόγιο πρόγραμμα της THEMA** (του φορέα εκμετάλλευσης του Μετρό):

- Πρώτο δρομολόγιο κάθε μέρα στις **05:15**, από τον δυτικό τερματικό σταθμό.
- Ώρα κλεισίματος δικτύου: Δευ–Πέμ & Κυρ 00:30 (επόμενη μέρα), Παρ–Σάβ 02:00 (επόμενη μέρα).
- Δύο ζώνες συχνότητας κάθε μέρα, με συχνότητα στον κοινό κορμό (Ν. Σιδηροδρομικός Σταθμός ↔
  25ης Μαρτίου) ανά ημέρα/ζώνη:

  | | 05:15–07:30 | 07:30–κλείσιμο |
  |---|---|---|
  | Δευ–Παρ | ανά 5′ | ανά 2:55′ |
  | Σάββατο | ανά 10′ | ανά 2:55′ |
  | Κυριακή | ανά 10′ | ανά 3:25′ |

  Οι συχνότητες στους δύο κλάδους (Νέα Ελβετία / Μίκρα) που δημοσιεύει η THEMA δεν αποθηκεύονται
  ξεχωριστά — προκύπτουν ακριβώς από τον διαχωρισμό 2:1 (βλ. παρακάτω) πάνω στη συχνότητα του
  κορμού: π.χ. Δευ–Παρ μετά τις 07:30, κορμός ανά 2:55′ → Νέα Ελβετία ανά 3×2:55=8:45′, Μίκρα κατά
  μέσο όρο ανά 1,5×2:55=4:23′ — ταιριάζει ακριβώς με όσα δημοσιεύει η THEMA.
  *(Οι "Αργίες" ακολουθούν επίσημα το πρόγραμμα Κυριακής, αλλά η εφαρμογή δεν έχει ημερολόγιο
  αργιών — αναγνωρίζει μόνο την ίδια την Κυριακή.)*
- Χρόνος διαδρομής: ~16′ στον κορμό (Ν. Σιδηροδρομικός Σταθμός → 25ης Μαρτίου) + ~3′ στον κλάδο
  προς Νέα Ελβετία ή ~11′ στον κλάδο της επέκτασης προς Μίκρα — παραδοχή, όχι επίσημο στοιχείο.
- Πριν από το "σκάλωμα" στις 07:30 (από την αραιή πρωινή ζώνη στην κανονική), επιπλέον συρμοί
  μπαίνουν σταδιακά στο δίκτυο με αφετηρία το depot κοντά στη **Νέα Ελβετία** (ισχύει και για τους
  συρμούς που καταλήγουν στην Καλαμαριά, αφού δεν υπάρχει ξεχωριστή πληροφορία για αυτούς) — το
  διάστημα μειώνεται σχεδόν γραμμικά μέχρι να φτάσει στην τιμή των 07:30, μέσα σε **~12 λεπτά** πριν
  (επιβεβαιωμένο εύρος: 10–15′, `SCHEDULE.rampMinutes`). Έτσι η γραμμή δεν "πηδάει" ξαφνικά σε
  πυκνότερα δρομολόγια ακριβώς στις 07:30.

**Τοπολογία σε σχήμα Y:** η γραμμή είναι ενιαία μέχρι τον σταθμό **25ης Μαρτίου**, όπου διακλαδίζεται:
ο ένας κλάδος οδηγεί στη Νέα Ελβετία (ήδη σε λειτουργία), ο άλλος στην επέκταση Καλαμαριάς
(Νομαρχία–Καλαμαριά–Αρετσού–Νέα Κρήνη–Μίκρα, ανοιχτή από 27/08/2026). Η επέκταση **δεν** συνεχίζει
μετά τη Νέα Ελβετία — ξεκινά νωρίτερα, από τη διακλάδωση. Τα δρομολόγια χωρίζονται σε αναλογία
**2:1 υπέρ της Καλαμαριάς** (από κάθε 3 συρμούς που φεύγουν από τον κορμό, οι 2 πάνε προς Μίκρα και
1 προς Νέα Ελβετία) — επιβεβαιωμένη αναλογία, όχι υπόθεση 50/50, και συνεπής με τους παραπάνω
αριθμούς της THEMA.

Με βάση αυτά τα δεδομένα, υπολογίζεται πόσοι συρμοί κυκλοφορούν αυτή τη στιγμή προς κάθε
κατεύθυνση/κλάδο και πού βρίσκονται πάνω στη γραμμή. **Δεν πρόκειται για πραγματικά δεδομένα GPS.**

Στοιχεία δρομολογίων/σταθμών βάσει του επίσημου προγράμματος της THEMA, [thessmetro.gr](https://www.thessmetro.gr)
και δημοσιευμάτων για την επέκταση προς Καλαμαριά. Οι συντεταγμένες κάθε σταθμού προέρχονται από το
infobox του αντίστοιχου άρθρου στην Αγγλική Wikipedia (πραγματικές, όχι σχηματικές θέσεις).

## Χαρακτηριστικά

- Πραγματικός γεωγραφικός χάρτης ([Leaflet](https://leafletjs.com/) πάνω σε πλακίδια Esri World Light
  Gray Canvas — δωρεάν, χωρίς να απαιτείται API key) με τη γραμμή σε σχήμα Y (11 σταθμοί κορμού + 2
  σταθμοί προς Νέα Ελβετία + 5 σταθμοί επέκτασης Καλαμαριάς) στις πραγματικές τους θέσεις, με
  ζωντανά κινούμενους δείκτες συρμών ανά κλάδο/κατεύθυνση.
- Ανοιχτόχρωμο, λιτό interface: ο χάρτης γεμίζει όλη την οθόνη και τα στοιχεία ελέγχου (κατάσταση
  δικτύου, ρολόι, συχνότητα, στόλος, πίνακας σταθμού) επιπλέουν από πάνω του σαν ημιδιάφανα
  "floating" πάνελ, με λάμπουσες γραμμές γεωγραφικού χάρτη — εμπνευσμένο από το
  [amsterdammetro.nl](https://amsterdammetro.nl/).
- Ρολόι σε ώρα Ελλάδας (Europe/Athens) ανεξάρτητα από τη ζώνη ώρας του επισκέπτη.
- Ένδειξη ανοιχτού/κλειστού δικτύου και τρέχουσας ζώνης συχνότητας (πρωινή/κανονικό πρόγραμμα).
- Ένδειξη πόσοι συρμοί είναι αυτή τη στιγμή σε κίνηση, πάνω στο γνωστό μέγεθος του στόλου (18
  συρμοί σήμερα, 33 μετά την επέκταση — δεδομένα του operator). Ο στόλος λειτουργεί σαν πάνω όριο
  στην προσομοίωση, όχι απλή ένδειξη.
- Αυτόματη ενεργοποίηση της επέκτασης Καλαμαριάς στις 27/08/2026, με αντίστροφη μέτρηση μέχρι τότε.
- Κλικ σε σταθμό → επόμενες 3 αφίξεις ανά κατεύθυνση, ομαδοποιημένες ανά τελικό προορισμό στους
  κοινούς σταθμούς του κορμού.
- Responsive design· τα ονόματα σταθμών εμφανίζονται μόνιμα μόλις μεγεθύνεις αρκετά (οι πραγματικοί
  σταθμοί απέχουν μόνο μερικές εκατοντάδες μέτρα μεταξύ τους), αλλιώς φαίνονται με hover/tap. Σε
  στενές οθόνες (κινητό) το υπόμνημα γραμμών και το μπάνερ επέκτασης αποκρύπτονται για να μη
  στριμώχνονται πάνω στον χάρτη — τα βασικά στοιχεία (κατάσταση, ρολόι, συχνότητα, στόλος, πίνακας
  σταθμού) παραμένουν.

## Εκτέλεση τοπικά

Δεν χρειάζεται build step — καθαρό HTML/CSS/JS. Απλά σέρβιρε τον φάκελο στατικά, π.χ.:

```bash
python3 -m http.server 8000
# άνοιξε http://localhost:8000
```

## Deploy

Μπορεί να φιλοξενηθεί σε οποιοδήποτε static hosting (π.χ. GitHub Pages): ενεργοποίησε το Pages
για αυτό το repo/branch, με root τον φάκελο του repository.

## Δομή

```
index.html          Markup της σελίδας
css/style.css        Στυλ (dark theme, χάρτης, panels)
js/data.js           Σταθμοί (πραγματικές συντεταγμένες), μοντέλο ωραρίου
js/app.js            Μηχανή υπολογισμού δρομολογίων + Leaflet rendering + interactivity
vendor/leaflet/      Αυτοφιλοξενούμενη βιβλιοθήκη Leaflet (χωρίς εξάρτηση από CDN)
vendor/fonts/        Αυτοφιλοξενούμενες γραμματοσειρές Inter + JetBrains Mono (Latin + Greek)
```

## Ιδιωτικότητα

Η σελίδα δεν χρησιμοποιεί cookies ούτε analytics/εργαλεία παρακολούθησης. Όλες οι εξωτερικές
εξαρτήσεις (Leaflet, γραμματοσειρές) είναι αυτοφιλοξενούμενες στο `vendor/` — δεν φορτώνονται από
CDN τρίτων (π.χ. Google Fonts), ώστε να μην μεταδίδεται η IP του επισκέπτη σε τρίτους για κάτι τόσο
βασικό όσο η γραμματοσειρά. Η μόνη εξαίρεση είναι τα πλακίδια του χάρτη (Esri), απαραίτητα για την
ίδια τη λειτουργία της σελίδας. Η μόνη τοπική αποθήκευση (`localStorage`) είναι ένα flag που θυμάται
αν έχεις κλείσει το εισαγωγικό μήνυμα — καμία σχέση με tracking.
