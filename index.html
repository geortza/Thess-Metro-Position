Δεν υπάρχει επίσημο δημόσιο API για ζωντανή θέση συρμών. Οι θέσεις εδώ είναι εκτίμηση, υπολογισμένη από το ωρολόγιο πρόγραμμα (πρώτο/τελευταίο δρομολόγιο ανά τερματικό σταθμό και συχνότητα 3′ σε ώρες αιχμής / 5′ εκτός αιχμής) — όχι πραγματικά δεδομένα GPS. Στοιχεία δρομολογίων βάσει thessmetro.gr.
